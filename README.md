# RoboBoat

Our RoboBoat protoype is an unmanned RC boat with autonomous capabilities which is otherwise known as an Autonomous Surface Vehicle (ASV). Designed and constructed for our Cal Poly Pomona Senior Design Project, it is intended to be a foundation for creating an eligible competitor for the RoboBoat competition.  The boat's current autonomy level is classified as low since it operates using GPS-based waypoint navigation and has an RC override for users to take control at any time.  However, planned future improvements will increase the autonomy level with the addition of object detection and object avoidance capabilities.

This repository is the documentation of our work including tutorials for future contributors.

## Essential Hardware and Firmware

The Pixhawk 2.4.8 flight controller is the main component and it performs the essential the entire system depends on it.  It has the ArduPilot Rover firmware flashed into it.

## Software Installation

Install Mission Planner.  It is essential for the configuration of the Pixhawk and Ardupilot firmware, and provides a convenient GUI for users to interface with everything.
